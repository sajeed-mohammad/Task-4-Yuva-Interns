# Task 4 - Predictive Modeling and Optimization

## Project Title

Logistics Delivery Delay Prediction and Optimization

## Objective

The objective of Task 4 is to develop a machine learning model that predicts delivery delays and converts the prediction into practical operational recommendations.

## Problem Statement

The logistics company wants to identify deliveries that are likely to be delayed before the delivery occurs.

The predictive system estimates the probability of delay and assigns each delivery a risk level.

## Machine Learning Algorithm

The project uses:

### Random Forest Classifier

Random Forest is an ensemble machine learning algorithm that combines multiple decision trees to make predictions.

## Input Features

The following features are used:

- Warehouse
- Customer Location
- Delivery Distance
- Transportation Mode
- Package Weight
- Delivery Priority
- Weather Condition
- Traffic Level
- Warehouse Processing Time
- Planned Delivery Time
